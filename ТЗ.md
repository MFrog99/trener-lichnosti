# Тренер личности — техническое задание

Итог опроса от 18.11.2026.

## Платформы и аккаунты
- **Сайт** + **Windows-программа** + **Android-приложение**, всё из одного кода.
- Приложение **публичное**: регистрация и вход по **email + пароль**, данные синхронизируются между устройствами.
- **Бесплатное**, без монетизации.
- Язык интерфейса: **только русский**.
- Тема: **светлая и тёмная с переключателем**.

## Технологии
| Часть | Решение |
|---|---|
| Интерфейс | React + TypeScript + Vite, PWA (работает офлайн) |
| Бэкенд | Supabase (бесплатный тариф): Auth, PostgreSQL, Row Level Security |
| Защита от «засыпания» Supabase | GitHub Actions по расписанию раз в 2 дня делает запрос к базе |
| Сайт | GitHub Pages, деплой автоматически через GitHub Actions |
| Windows | Electron → установщик `.exe`, собирается в GitHub Actions |
| Android | Capacitor → `.apk`, собирается в GitHub Actions (Android Studio не нужен) |
| Офлайн | Данные сначала пишутся локально, при появлении сети синхронизируются |

## Разделы
1. **Главная** — план на день, уровень/XP, серия дней, быстрая отметка настроения, цитата дня.
2. **Тренировки**
   - без инвентаря и с гантелями/резинками;
   - уровни: новичок / средний / продвинутый, программы на несколько недель;
   - конструктор своих тренировок из библиотеки упражнений;
   - плеер тренировки: таймер работы/отдыха, звуковые сигналы, пауза/пропуск;
   - техника: текстовое описание + векторная анимация-схема;
   - история тренировок.
3. **Релакс**
   - дыхательные техники с анимированным кругом (4-7-8, квадратное, 4-6 и др.);
   - фоновые звуки (дождь, океан, лес, шум) с микшером и таймером сна;
   - медитации с озвучкой синтезатором речи (сканирование тела, заземление 5-4-3-2-1 и др.);
   - расслабляющая растяжка/йога (перед сном, после работы).
4. **Развитие личности**
   - черты: уверенность, дисциплина, коммуникация, эмпатия, стрессоустойчивость, креативность, осознанность;
   - входной тест-самооценка, диаграмма-«паутина», повторный тест раз в месяц;
   - курсы по дням (21–30 дней на черту): короткая теория + задание дня;
   - рефлексия после каждого задания.
5. **Дневник и настроение** — записи, подсказки для письма, график настроения.
6. **Трекер привычек** — свои привычки, отметки по дням, серии.
7. **Цели и планы** — цели с этапами и дедлайнами.
8. **Геймификация** — XP, уровни, достижения, серии дней.
9. **Социальное** — друзья (по нику/коду), рейтинг по XP, совместные челленджи на N дней.
10. **Напоминания** — уведомления на Android, Windows и в браузере.
11. **Профиль** — ник, аватар, тема, настройки напоминаний, экспорт данных, удаление аккаунта.

## Юридическое
- Дисклеймер «не является медицинской консультацией» (в тренировках и релаксе).
- Галочка согласия на обработку данных при регистрации.
- Черновик политики конфиденциальности и пользовательского соглашения (показать юристу перед запуском).

## Порядок работы
- Разработка **всего сразу**, показ в конце.
- Максимум автоматизации: всё, что можно настроить скриптами и GitHub Actions, настраивается без участия пользователя.

## Что неизбежно сделать пользователю (займёт ~10 минут)
Создавать аккаунты и вводить пароли за пользователя нельзя, поэтому:
1. Зарегистрироваться на supabase.com, создать проект и передать: **Project URL**, **anon key** и **Access Token** (по нему таблицы и настройки базы создаются автоматически).
2. Разрешить установку **Git** (через winget) и один раз войти в GitHub в браузере, чтобы залить код.
3. После загрузки кода — проверить, что в репозитории включены GitHub Pages и Actions (подскажу, куда нажать).
