# 🌱 Тренер личности

Приложение для домашних тренировок, релаксации и развития личностных черт.
Работает как **сайт**, **программа для Windows** и **приложение для Android** из одного кода.

## Что внутри

| Раздел | Возможности |
|---|---|
| 🏠 Главная | План на день, уровень и опыт, серия дней, настроение, активность за 30 дней |
| 💪 Тренировки | 8 программ (новичок → продвинутый; без инвентаря, гантели, резинка), плеер с таймером, голосом и анимацией техники, конструктор своих тренировок, библиотека из 40+ упражнений, история |
| 🧘 Релакс | 7 дыхательных техник с анимацией, микшер из 9 звуков природы с таймером сна, 7 медитаций с озвучкой, 4 комплекса растяжки и йоги |
| 🚀 Развитие | Тест 7 черт с диаграммой-«паутиной», курсы по 21 дню (147 заданий), рефлексия |
| 📔 Дневник | Записи с подсказками, отметки и график настроения |
| ✅ Привычки | Свои привычки по дням недели, серии |
| 🎯 Цели | Цели с этапами и сроками |
| 🏆 Достижения | XP, 20+ уровней со званиями, 26 достижений |
| 👥 Друзья | Код друга, рейтинг, совместные челленджи |
| ⚙️ Профиль | Тема (светлая/тёмная/системная), напоминания, экспорт/импорт, удаление аккаунта |

Приложение работает и без аккаунта: тогда данные хранятся на устройстве. После входа они переносятся в облако.

## Технологии

- React + TypeScript + Vite
- Supabase: вход по email, база PostgreSQL, правила безопасности RLS
- Electron — Windows, Capacitor — Android
- GitHub Actions: сайт на GitHub Pages, сборка `.exe` и `.apk`, автопинг Supabase

## Команды

```bash
npm install              # установка зависимостей
npm run dev              # запуск в браузере: http://127.0.0.1:5173
npm run electron         # запуск Windows-версии (после npm run build)
npm run dist:win         # установщик Windows → папка release/
npm run setup:supabase   # автоматическая настройка облака
```

## Настройка облака (один раз)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатно).
2. Создайте токен на странице [Access Tokens](https://supabase.com/dashboard/account/tokens).
3. Выполните `npm run setup:supabase` и вставьте токен.

Скрипт сам создаст проект, таблицы, правила безопасности и настройки входа, а затем запишет публичные ключи в файл `.env`.

> Подтверждение email отключено: встроенная почта Supabase отправляет лишь несколько писем в час, и при включённом подтверждении новые пользователи не смогли бы зарегистрироваться. Если нужно подтверждение, подключите свой SMTP-сервер в Supabase (Authentication → SMTP) и включите «Confirm email».

## Публикация

После загрузки кода в GitHub (ветка `main`) всё запускается автоматически:

- **Сайт** публикуется в ветку `gh-pages`. Адрес: `https://<логин>.github.io/trener-lichnosti/`. Если сайт не открывается, проверьте: Settings → Pages → Source: *Deploy from a branch* → `gh-pages`.
- **Программы**: в разделе Releases появляются `TrenerLichnosti-Setup.exe` и `TrenerLichnosti.apk`.
- **Автопинг**: раз в 2 дня приложение обращается к базе, чтобы бесплатный проект Supabase не ушёл в сон.

Чтобы обновления на Android ставились поверх старой версии, APK нужно подписывать одним постоянным ключом. Для этого задайте секреты репозитория `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`; ключ лежит в папке `signing/`, которая не попадает в git. **Храните эту папку**: без неё выпустить обновление для уже установленных приложений не получится.

## Перед публичным запуском

- Заполните поля в `[квадратных скобках]` в `src/pages/Legal.tsx` и покажите тексты юристу.
- Учтите требование ч. 5 ст. 18 закона 152-ФЗ о хранении персональных данных россиян на серверах в РФ. Серверы Supabase находятся за рубежом (Франкфурт).
